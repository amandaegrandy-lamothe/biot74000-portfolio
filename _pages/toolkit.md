_A curated catalogue of the tools, databases, and methods I have worked with,
organized by what they are used for._

## Sequence Analysis Tools

### BLAST (Basic Local Alignment Search Tool)

I used BLAST to compare a query sequence against NCBI databases and interpret alignment metrics such as E‑value, bit score, and percent identity. This helped me confirm sequence identity and locate homologs. One limitation is that BLAST results can be overwhelming without careful filtering.

### Clustal Omega 

I performed multiple sequence alignments with Clustal Omega to identify conserved regions across related sequences. A strength of this tool is its ability to generate high‑quality alignments with minimal setup, although it offers limited customization.

## Databases & Data Retrieval

### NCBI / GenBank  
I retrieved nucleotide sequences and metadata from GenBank to support BLAST searches and annotation review. GenBank is comprehensive and authoritative, but annotation quality varies across submissions.

### RefSeq  
I checked RefSeq accessions such as NM_, NP_, and NC_ to ensure I was using curated, stable reference sequences. RefSeq provides high‑quality annotations, but it may not include all known isoforms.

### UniProt
I retrieved protein sequences, functional annotations, and evidence codes from UniProt. UniProtKB/Swiss‑Prot provides high‑quality curated entries, while UniProtKB/TrEMBL may contain minimal annotation.

## Genome & Transcriptome Analysis

### Ensembl Genome Browser  
I navigated Ensembl gene models, transcripts, and variation data to cross‑validate findings from UCSC and NCBI. Ensembl provides strong cross‑species support, though naming conventions sometimes differ.

## Protein Structure & Function

### AlphaFold Protein Structure Database  
I viewed AlphaFold‑predicted protein structures to assess domain organization and potential functional sites. AlphaFold provides state‑of‑the‑art predictions, but confidence is lower in disordered regions.

### Gene Ontology (GO)  
I checked GO terms to understand biological processes, molecular functions, and cellular components associated with specific genes. GO offers standardized functional vocabulary, but evidence codes vary in reliability.

## Computational & Scripting Tools

### R  
I used R for basic data wrangling and visualization during exploratory analysis tasks. R is powerful for statistical workflows, but it requires familiarity with syntax and package management.

### GitHub  
I created and maintained a GitHub repository for my final project, including committing changes and publishing a GitHub Pages site. GitHub supports reproducible, collaborative work, but it requires understanding version control.

## Data Visualization

### R Graph Gallery  
I referenced the R Graph Gallery to guide plot design and improve the clarity of my visualizations. The gallery provides many reproducible examples, but each plot requires adaptation to my own dataset.
